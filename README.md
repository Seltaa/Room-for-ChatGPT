# Room for ChatGPT

Make ChatGPT feel like your own room. Room is a privacy-first Chrome extension for custom backgrounds, profiles, themes, message cards, an analog clock, and a styled composer.

## Features

- Five presets: Strawberry Cream, Lavender Dream, Butter Ribbon, Rose Night, and Midnight Blue
- Custom accent color and conversation width
- Local image backgrounds with opacity, blur, and position controls
- Animated GIF backgrounds up to 6 MB
- Separate names, emoji, and local avatars for you and ChatGPT
- Large profile labels above messages
- Rounded glass-style assistant message cards
- Custom composer color, opacity, roundness, and placeholder text
- Small analog clock with selectable positions
- Optional floating sparkles
- Live settings drawer inside ChatGPT

## Install

1. Download the ZIP from the latest GitHub Release.
2. Unzip it.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the unzipped folder.
7. Refresh `https://chatgpt.com` and use the **Room** button in the bottom-right corner.

## 설치 방법

1. 최신 GitHub Release에서 ZIP 파일을 다운로드합니다.
2. ZIP 압축을 풉니다.
3. Chrome에서 `chrome://extensions`를 엽니다.
4. 오른쪽 위의 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
6. 압축을 푼 폴더를 선택합니다.
7. `https://chatgpt.com`을 새로고침하고 오른쪽 아래 **Room** 버튼을 누릅니다.

## Privacy

- No server, analytics, ads, or tracking
- No chat text is stored or transmitted
- Settings, avatars, and backgrounds stay in `chrome.storage.local` in the current browser profile
- Site access is limited to `https://chatgpt.com/*`

## Notes

Room is an independent community project and is not affiliated with or endorsed by OpenAI. ChatGPT's interface changes over time, so selectors may occasionally require maintenance.
